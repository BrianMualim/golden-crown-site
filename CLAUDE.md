# Golden Crown Realty website: project notes

Running record of how this site is built and the decisions made so far. Keep it updated whenever the site changes: add new decisions, and edit or remove lines that are no longer true.

> This repo is public and GitHub Pages serves every file in it (including this one), so nothing private goes here.

## Basics
- **Live site:** https://goldencrownrealty.com (GitHub Pages, deployed from `main`, root folder)
- **Repo:** `BrianMualim/golden-crown-site`
- **Company:** Golden Crown Realty LLC, a real estate investment and holdings company in Los Angeles
- **Tech:** plain static HTML/CSS/JS. No framework, no build step. Push to `main` and the site updates in about 1–2 minutes.
- **Do not delete or edit `CNAME`.** It holds the custom domain (`goldencrownrealty.com`).

New pages copy the shell of `vacancies.html`: same `<head>` (fonts, `styles.css`, favicon links), the same header and footer, `<script src="script.js">`, and a `.page-hero` banner at the top. On sub-pages, nav links use `index.html#section`.

## Design
- **Colors** (CSS variables in `styles.css`): ink `#14171f` / `#1d2230`, paper `#faf8f3` / `#f1ede3`, gold `#b8964f`, light gold `#d9bf86`, muted text `#6b6f7a`
- **Fonts:** Cormorant Garamond for headings (serif), Inter for body text. Both load from Google Fonts.
- **Style:** dark navy hero and contact sections, cream content sections, a small uppercase gold "eyebrow" label above each heading, serif headings ending with a period.
- **Logo:** a placeholder gold crown SVG drawn in the header markup. No real logo file yet.
- `.reveal` fades elements in on scroll. `.ph` (dashed gold outline) marks placeholder text; none are left on the site right now.

## Home page sections (`index.html`, top to bottom)
1. **Header/nav:** About · Vacancies (goes to `vacancies.html`) · Approach · Focus Areas · Contact Us button
2. **Hero:** "Building lasting value in *Los Angeles* real estate." with Work With Us and Learn More buttons. Area line: "Los Angeles • Beverly Hills".
3. **About** (`#about`): "A Long-Term Approach to Real Estate." with `about_pic.jpg`. The frame is **4:3** on every screen size, and the gold border sits evenly **14px** outside the photo (`inset: -14px`).
4. **Projects carousel** (`#projects`): "Our Projects / Selected holdings. / A look at land and property across Los Angeles." **Photos only, no text on the cards** (the owner's request). Frames are **790:1024** portrait. Shows 3 across on desktop, 2 on tablet, 1 (85% width) on phone. Auto-advances every 4.5s and loops. Pauses on hover, focus, or touch. Arrows overlay the edges on desktop and are hidden on phones. Dots are generated by the script. Not in the nav menu.
5. **Approach** (`#approach`): "Invest with discipline. Create lasting value." with 3 cards: Value-Add Potential, Markets We Know, Cash Flow with Upside.
6. **Focus Areas** (`#focus`): heading "Our pillars." with the subtext "The principles behind every decision we make." Three items: Value-Add Opportunities, Select Neighborhoods, Cash Flow with Upside.
7. **Contact** (`#contact`): office 1620 Hi Point Street, Los Angeles, 90035 · (786) 525-7177 · teguh@goldencrownrealty.com · Mon–Fri 9–5. Has an inquiry form (name, email, phone, "I am a" dropdown, message).

## Vacancies page (`vacancies.html`)
- Dark `.page-hero` banner: "Vacancies / Available residences. / Browse our current openings…"
- Grid of `.vac-card` links. Each card opens the full listing on an outside site in a new tab. Shows 3 across on desktop, 2 on tablet, 1 on phone.
- **Card fields:** photo (4:3, cropped to fit), "Available" badge, neighborhood, address, beds/baths/sq ft, and a "View listing on Zillow ↗" link.
- **No rent is shown on cards on purpose.** Prices change and go stale; the outside listing shows the current price.
- A "Contact Us" prompt at the bottom links to `index.html#contact`.
- **Current listings:**
  - 5947 Carlton Way, Hollywood, Los Angeles, CA 90028. 1 bed, 1 bath, 700 sq ft. Photo `carlton.jpg`. Zillow: https://www.zillow.com/apartments/los-angeles-ca/5947-carlton-way/5YyKf6/
- **To add a unit:** copy one `<a class="vac-card">…</a>` block. **When a unit rents:** delete its card.

## Known to-dos / open items
- **The contact form doesn't send yet.** Its action is still `https://formspree.io/f/YOUR_FORM_ID`. Sign up at formspree.io with the receiving inbox and replace the endpoint. The first submission sends an activation email.
- The logo is a placeholder crown SVG.
- The hero uses a gradient background. A photo could be added; there's a commented CSS line for it in `styles.css`.

## Image guidelines
- Keep each image under about 300 KB (JPG at about 80% quality) so pages load fast.
- File names are case-sensitive on GitHub Pages.
- Size by slot: carousel 790×1024, about 4:3 (1600×1200), listing cards 4:3, hero background (if added) about 2400×1350.
